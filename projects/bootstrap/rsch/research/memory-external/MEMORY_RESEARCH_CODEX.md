# 시행착오를 다음 작업에 쓰는 기억으로 만드는 방법 — Codex

조사일: 2026-10-14. 범위는 공식 문서 사례 3개와 현재 rsch 기록의 수정이다. 제품 설치·동작 시험이나 효과 벤치마크는 수행하지 않았다.

우리가 원하는 결과는 다음 에이전트가 자기 작업대에 도착하여 필요한 기억을 받아 일을 이어가고, 이전 경험 덕분에 사용자의 재설명과 반복 작업이 줄어드는 것이다. 이번 누락은 기억 파일이 있어도 합의와 결과를 제때 반영하지 않으면 그 연결이 끊긴다는 사례다.

## 외부에서는 어떻게 처리하는가

| 사례 | 저장·갱신 | 다음 작업에서 사용 | 우리에게 참고되는 부분 |
|---|---|---|---|
| Cline Memory Bank | 프로젝트 안의 Markdown에 목적·현재 상황·진행 상태 등을 나눠 기록. 규칙 파일과 갱신 요청을 사용한다. | 작업 시작에 기억을 읽도록 지시한다. | 저장 위치와 갱신 시점을 명시하는 작은 출발점. 규칙 준수를 실행기가 강제한다는 증거는 아니다. |
| Claude Code auto memory | 에이전트가 사용자 정정·선호 등 보존할 내용을 선택해 로컬 프로젝트별 기억에 저장한다. | MEMORY.md 앞 200줄 또는 25KB까지 시작에 읽고 상세 파일은 필요할 때 읽는다. | 짧은 진입점과 상세 기억 분리. 모든 정정이 저장되거나 실제로 준수된다는 보장은 없다. |
| Letta MemFS | Markdown 기억을 Git 저장소로 관리하며 로컬 전용 에이전트도 로컬 저장소에 커밋한다. | 루트 기억은 매 turn 시스템 프롬프트에, 하위 기억은 색인을 통해 필요할 때 읽는다. | 기억의 버전 관리와 입력 구성을 실행환경의 기능으로 제공한다. 기본 검색은 파일 검색이며 벡터 색인이 필수는 아니다. |

근거: [Cline Memory Bank](https://docs.cline.bot/best-practices/memory-bank), [Claude Code memory](https://code.claude.com/docs/en/memory), [Letta MemFS](https://docs.letta.com/concepts/memfs). Claude 설명은 열람일의 공식 문서 기준이며 설치된 버전의 별도 실측으로 간주하지 않는다.

Letta의 dreaming은 대화를 검토하여 교훈을 정리하는 백그라운드 작업이다. 명시적으로 기억을 요청할 수 있고, 반영 전 다른 에이전트 검토도 선택할 수 있다. 이 검토는 사람의 승인 절차가 아니며 추가 모델 토큰이 든다. 사용자 구상의 “경험을 리뷰해서 다음 작업에 활용”과 연결되는 참고 사례다. 다만 우리 요구에 맞는 역할 소유권과 적용 범위까지 해결됐다고 단정할 수는 없다. [Letta Memory & dreaming](https://docs.letta.com/configuration/memory)

## 우리 요구와 대조한 해석

1. **기록:** 사용자 정정과 결과 수신 시점에 실제 파일을 갱신해야 한다. Git은 쓰지 않은 메모를 대신 만들어 주지 않는다.
2. **검토:** 작업 기록에서 교훈을 추출할 때 적용 조건·근거·미확인 사항을 보존해야 한다. 모델의 자동 요약은 검토할 후보가 된다.
3. **전달:** 짧은 현재 상태와 관련 경험을 다음 세션 입력에 연결해야 한다. 저장과 입력 포함은 별도 단계다.
4. **행동 확인:** 입력에 들어간 내용대로 작업대와 업무를 인수했는지 확인해야 한다. 지침과 기술적 실행 차단은 별개다.
5. **효용:** 같은 설명·실수·탐색·구현을 얼마나 줄였는지 다음 업무에서 확인해야 한다. 기록량이나 커밋 수만으로 성공을 판정하지 않는다.

위 다섯 항목은 사례와 우리 실패를 대조한 설계 해석이다. 현재 세 제품 중 어느 하나가 전체 요구를 충족한다고 검증한 것은 아니다. 특히 “프로젝트·역할별 작업대가 여러 실행환경을 넘어 경험을 소유한다”는 부분은 별도 설계가 필요하다.

- 완료된 Claude 진입 조사의 “예정” 상태를 수정했다.

기억 파일은 로컬에 저장했다. Git 커밋·자동 주입·실행 차단은 이번 작업에서 구현하지 않았다. 새 세션이 이 기록을 실제로 읽고 이어가는지는 다음 검증 대상으로 남긴다.
