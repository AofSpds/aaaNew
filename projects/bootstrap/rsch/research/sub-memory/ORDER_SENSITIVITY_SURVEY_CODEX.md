# 기억 관계 판정의 순서 민감도: 외부 연구 조사

작성: 2026-10-14 KST. 범위: 기억 관계 범주 선택과 “수정 없이 함께 보존할 때의 양립 검토” 분류. 제품 운영 기준은 아직 제안이다.

## 순서를 나누어 봐야 하는 이유

| 순서 | 바꾸어도 의미가 같아야 하는 조건 | 이번 로컬 시험 |
|---|---|---|
| 관계 범주 선택지의 나열 | 범주 ID와 설명을 그대로 유지 | 원순·역순·ID순·설명 길이순·이전 점수순·두 무작위순·순환 배치 |
| 기억 A/B의 표시 위치 | A/B 이름·내용·역할·시점은 유지 | B 먼저 표시 |
| 판단 예시의 배열 | 예시 집합은 동일 | 미시험 |
| 긴 기억 묶음에서 근거의 위치 | 근거 집합·시점은 동일 | 미시험 |
| 실제 사건·개정·적용의 순서 | 앞뒤가 의미를 바꾸므로 동일성 가정 불가 | 미시험; 별도의 시간·대체 관계 문제 |

고정 정렬은 입력을 재현하기 쉽게 한다. 그 정렬의 판단이 옳은지, 다른 정렬에서도 유지되는지는 따로 확인해야 한다. 선택지 순서와 기억 표시 위치의 상호작용도 이번 시험에서는 교차 조합하지 않았다.

## 1. 선택지 순서와 여러 배치의 집계

Pezeshkpour & Hruschka, NAACL Findings 2024, [Large Language Models Sensitivity to The Order of Options in Multiple-Choice Questions](https://aclanthology.org/2024.findings-naacl.130/), [발표 PDF](https://aclanthology.org/2024.findings-naacl.130.pdf).

3개 모델·5개 벤치마크에서 선택지 순서를 바꿨다. Table 5의 무작위 10회 배치 다수결은 Logical Deduction에서 InstructGPT 64.0→72.0%, GPT-4 92.3→94.3%였다. 모델·과제별 효과가 달랐고 설명을 먼저 생성하는 방법도 일관되게 개선하지 않았다. 초록의 13–85% 성능 차이는 정답을 아는 최선·최악 배치 비교이므로 일반 무작위 변경률로 읽으면 안 된다.

우리 적용: 여러 배치에서 분포·최상위 답·검토 경로를 함께 비교한다. 10회 추론 비용과 우리 자료의 검토 감소 효과를 별도로 재야 한다. 위 향상치를 Kev의 기대 효과로 사용하지 않는다. 확인 수준: 발표본 초록, 본문, Table 1·5.

## 2. 같은 입력의 반복 안정성과 순서 안정성은 다르다

Shi et al., IJCNLP-AACL 2025, [Judging the Judges](https://aclanthology.org/2025.ijcnlp-long.18/), [발표 PDF](https://aclanthology.org/2025.ijcnlp-long.18.pdf).

발표본은 15개 판정 모델·22개 과제·약 40개 생성 모델의 15만 건 이상 평가다. 반복 안정성, 위치 일관성, 선호 공정성을 나누었다. Table 2에서 GPT-4의 MTBench 반복 안정성은 0.97, 위치 일관성은 0.82였다. 이는 정답률이 아니다. 순서 효과는 단순 무작위 변동으로 설명되지 않았고, 판정 모델·과제·후보 품질 차이의 영향을 받았다.

우리 적용: 동일 입력을 다시 실행하는 통제를 둔다. 반복 결과가 같아도 순서에 안전하다고 결론 내리지 않는다. 초기 arXiv의 12개/10만 건 수치와 발표본을 섞지 않는다. 확인 수준: 발표본 초록·본문·Table 2.

## 3. 판단 예시의 순서도 영향을 준다

Lu et al., ACL 2022, [Fantastically Ordered Prompts and Where to Find Them](https://aclanthology.org/2022.acl-long.556/).

이는 선택지 순서가 아니라 few-shot 예시 순서 연구다. 같은 예시라도 배치에 따라 성능이 크게 변했고 좋은 배치가 모델 간에 그대로 이전되지 않았다. 인공 개발 자료와 엔트로피를 활용한 배치 선택은 GPT 계열 11개 분류 과제에서 평균 약 13%의 상대 개선을 보고했다. 13%p 향상이라는 뜻이 아니다.

우리 적용: 향후 검토된 기억 예시를 프롬프트에 넣을 때 예시 순서와 모델 버전을 실험 조건으로 보존한다. 현재 예시 없는 관계 질문의 효과와 합산하지 않는다. 확인 수준: 발표본 초록.

## 4. 긴 기억에서 근거의 위치

Liu et al., TACL 2024, [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/), [발표 PDF](https://aclanthology.org/2024.tacl-1.9.pdf).

다중 문서 QA와 key-value 검색에서 근거가 앞·뒤에 있을 때보다 중간에 있을 때 성능이 낮은 경우를 관찰했다. 모델과 과제에 따라 형태가 달랐고 긴 문맥 지원만으로 문제가 없어지지 않았다. 질문 배치 변경도 과제별 효과가 달랐다.

우리 적용: 여러 기억·출처·그래프 경로를 전달할 때 동일 근거를 처음·중간·끝에 둔 별도 시험이 필요하다. 짧은 두 기억의 A/B 교환으로 긴 문맥 효과를 검증했다고 하지 않는다. 확인 수준: 발표본 초록·본문 2.3/4.2·부록.

## 5. 점수 보정과 “정보 부족”의 구별

Zhao et al., ICML 2021, [Calibrate Before Use](https://proceedings.mlr.press/v139/zhao21c.html).

내용 없는 입력의 답변 분포로 편향을 추정하고 보정하는 방법을 제시해 few-shot 성능과 안정성 개선을 보고했다. 순서·형식에서 생기는 기본 선호를 추정한다는 점이 관련된다.

우리 적용 제안: 선택지 위치별 기본 선호를 관찰하되, 정보 없는 입력에서 “정보 부족”을 택하는 정상 행동까지 균등 분포로 강제하지 않는다. 이 기억 과제에 맞는 별도 검증 없이 N/A 보정을 그대로 쓰거나 temperature 조정과 동일시하지 않는다. 확인 수준: 공식 PMLR 초록.

## 6. 아예 집합의 순서에 불변인 구조

Lee et al., ICML 2019, [Set Transformer](https://proceedings.mlr.press/v97/lee19d.html).

순서 없는 집합 입력을 위한 attention 기반 구조다. 순열 불변성을 설계 조건으로 두며 inducing point를 이용한 계산량 절감도 제안한다. 기억 관계 분류나 한국어 Kev 성능을 측정한 논문은 아니다.

우리 적용 제안: 범주나 독립 근거를 집합으로 다루는 구조는 장기 비교 대상이다. 개별 기억 내부의 문장 순서와 실제 사건 시점은 보존해야 한다. 확인 수준: 공식 PMLR 초록.

## 7. 판정 편향을 학습으로 줄이는 최근 연구

Yang et al., ICML 2026, [FairJudge](https://proceedings.mlr.press/v306/yang26n.html).

공식 초록은 SFT·DPO·GRPO를 이용한 판정 정책 학습과 선택된 비의미적 편향 및 판정 일관성 개선을 보고한다. 이 조사에서는 초록만 확인했고 세부 수치·전체 실험 조건은 검증하지 않았다.

우리 적용 제안: 향후 충분한 독립 검토 자료가 생겼을 때의 학습 경로 후보로만 둔다. 현 18개 사례를 학습 적합성의 근거로 사용하지 않는다.

## 실제 Kev 구현에서 확인한 경계

[Kev model.py 고정 소스](https://github.com/jaredpalmer/kev/blob/0a6d3fafeee7f3f76a9a4a522bf8b9d5b50bd7e5/kev/model.py#L87): option_isolation은 선택지를 별도 분기로 만들고 같은 위치 ID를 부여하는 경로다. 하지만 같은 파일 263행은 hybrid 기반에서 이 설정을 거부한다. 현재 시험한 Kev 0.8B의 Qwen3.5 hybrid 경로에 옵션 하나만 켜서 적용할 수 없다. 질문 사이 격리와 선택지 순서 불변성을 혼동하지 않는다. 소스 설명을 읽은 것이며 다른 기반 모델에서 불변성을 실행 검증하지 않았다.

## 사용자 정정에 따른 연구 방식

2026-10-14 사용자: “외부연구가 많다면 외부연구결과에 대한 해석 자체검증 정도였으면 합니다”.

외부 근거가 충분하면 문헌의 결과·조건·한계를 종합하는 데 중심을 둔다. 자체 검증은 해석의 오류와 우리 상황의 적용 경계를 확인하는 최소 범위다. 자료 수집 확대나 전체 벤치마크 재현을 기본 다음 단계로 삼지 않는다.

각 주장에는 외부 근거, 모델·언어·과제·평가 조건, 확인 수준, 우리 해석, 남는 적용 조건을 연결한다. 논문 수뿐 아니라 관련성과 근거의 질을 확인한다. 이미 확인한 본문·코드·기존 자체 관찰을 먼저 사용하고, 결정에 필요한 미해결 쟁점이 있을 때만 좁은 자체 확인을 추가한다.

| 해석할 쟁점 | 현재 자료로 가능한 판단 | 최소 확인의 경계 |
|---|---|---|
| 순서가 판정에 영향을 줄 수 있다 | 외부 연구와 기존 로컬 관찰이 같은 방향을 보인다 | 로컬 변화 비율을 일반 빈도로 확대하지 않는다 |
| 여러 배치를 집계하면 개선된다 | 외부의 특정 조건에서 개선됐지만 현재 작은 로컬 시험에서는 이전되지 않았다 | 모델·과제·무작위 다수결과 순환 평균의 차이를 먼저 대조한다. 논문 재현 실패로 부르지 않는다 |
| 순서가 안정적이면 검토를 생략할 수 있다 | 현재 근거만으로 성립하지 않는다 | 반복/순서 안정성과 정답·검토 누락 지표를 구별한다 |
| 긴 기억의 위치 효과를 짧은 두 기억에 그대로 적용할 수 있다 | 문맥 길이와 과제가 달라 직접 환산할 수 없다 | 긴 기억 전달 설계를 실제로 결정할 때 관련 조건부터 확인한다 |

[로컬 시험](ORDER_SENSITIVITY_RESULTS_CODEX.md)은 18쌍의 탐색 관찰이다. 외부 연구의 정식 재현이나 일반 효과의 독립 입증으로 취급하지 않는다. 원자료는 memory-pilot-20261014/runs/order_study_v1에 보존한다.
