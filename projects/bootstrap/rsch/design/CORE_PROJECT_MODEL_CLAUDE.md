## 2. 프로젝트 모양

```text
projects/<프로젝트>/
├─ pln/    기획 — 프로젝트 로드맵, 배정, 수용
├─ rsch/   연구·시험
├─ arch/   설계 정본
├─ pmo/    구현 기록 (코드는 apps/)
└─ (V는 넘길 때 열고 판정만)
각 역할: Current 한 장(메모리 뷰) · 자기 로드맵 · 로컬 작업대
요청·회신: 프로젝트 안 한 곳. 도메인을 넘는 것만 domains 쪽 coordination
```

## 3. 로드맵 층

```text
도메인 로드맵 (DPM)        AAA_NEW-M1 → AAA_NEW-M2 …   ✔ 이름
 └ 프로젝트 로드맵 (PLN)    BTSR-P1 → BTSR-P2 → … 완료      각 단계는 어느 도메인 M을 위한 것인지 적음
    └ 역할 로드맵           RSCH·ARCH·PMO 각자 범위     각 단계는 어느 프로젝트 P를 위한 것인지 적음
```
