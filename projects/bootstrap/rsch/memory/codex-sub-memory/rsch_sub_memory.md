이미 완료한 18쌍·282회 시험은 작은 탐색 관찰로 보존한다. 외부 논문의 재현 성공·실패 또는 일반 효과 입증으로 표현하지 않는다. 선택지 순서 효과와 점수 변화가 우리 입력에서도 발생할 수 있음을 확인한 보조 근거이며, 여러 배치 평균의 개선이 그대로 이전되지 않았다는 적용 경계도 남긴다. 신규 독립 사례 확보, 긴 문맥·교차 배치 시험은 현재 자동으로 진행할 다음 단계에서 제외하고 필요성이 생겼을 때만 좁게 검토한다.

외부 순서 연구 조사와 로컬 결과 보고서에 이 연구 방향과 자료의 지위를 반영했다. 이번 상세 브리핑을 위해 NAACL 2024의 10회 무작위 다수결 및 Table 5, IJCNLP-AACL 2025의 Table 2와 발표본 규모, SelectiveNet·확률 보정·예시 순서·긴 문맥 위치 연구의 공식 원문을 재확인했다. 새 모델 호출·자료 수집·학습·제품 변경은 하지 않았다. L01 검토 질문은 계속 미응답이며, 사용자는 모바일이다.

브리핑 해석: 순서 영향의 존재는 여러 외부 과제에서 지지되지만 최적 정렬·집계 이득·검토 생략 기준은 조건부다. 같은 입력 반복, 순서 변경 일관성, 실제 정답률을 구별한다. 선택적 예측의 risk–coverage 관점은 재검토 분류 목적에 관련되지만 Kev에 그 기능과 기준이 검증됐다는 뜻은 아니다. 모델 내부 가중치·범주 점수·업무 영향 가중치는 별개다. 현재 Kev 0.8B의 한국어 기억 자료에서 규칙을 넘어선 검토 절감 효과는 입증되지 않았다. 외부 다수결과 로컬 순환 평균을 같은 방법으로 취급하지 않는다.

## 직전 탐색 시험과 근거

직전 탐색 시험을 요청한 사용자 지시는 “네 그외에 순서도 중요하다고 했습니다. 순서 소팅방법에 얼마나 영향을 받는지 보고 일단 비슷한 외부 연구주제와 결과도 봅시다”다. [순서 시험 결과](../../research/sub-memory/ORDER_SENSITIVITY_RESULTS_CODEX.md)와 [외부 순서 연구 조사](../../research/sub-memory/ORDER_SENSITIVITY_SURVEY_CODEX.md)를 만들었다.

기존 18쌍·두 문항에서 원순, 역순, 범주 ID순, 설명 문자 수순, 이전 점수순, 두 무작위순, 순환 배치, 기억 B 먼저 표시를 비교했다. 384개 방법 할당을 같은 입력끼리 합쳐 282개 실제 Kev 0.8B CPU float32 추론을 완료했다. 3쌍의 동일 입력 반복 6문항은 확률까지 같았고, 이전 실행과 이번 원순의 답 변경 0/36·최대 확률 차이 3.28e-7이었다. 입력 절단·원문 변경·라벨 입력 혼입은 없었다. 고정 모델/코드는 첫 시험과 같고 자세한 버전은 결과 보고서와 run.json에 있다.

선택지 배치 중 답이 한 번이라도 바뀐 것은 겹침 10/18, 양립 5/18이다. 양립의 5개 모두 보존 후보/검토 경로가 바뀌었다. 역순은 11/36 답 변경, 설명 길이순 5/36, 이전 점수순 0/36, 기억 표시 위치 변경은 8/36이다. 선택지 배치에서도 제안과 다르게 유지된 문항은 10/36(겹침 5·양립 5)으로, 순서 안정성은 정답 보장이 아니다.

기억 B 먼저 표시는 양립 경로 3/18을 바꿨으며 L04의 의무/금지 충돌을 보존 후보로 돌렸다. A “업무 시작 시 역할과 작업대 경로를 반드시 확인한다”, B “...확인해서는 안 된다”의 이름·내용·시점·상황은 그대로였다. 원순은 충돌 0.3823, B 먼저는 양립 0.3710이었다. 기존 제안 기준 검토 필요 누락 1건이므로 앞선 원순 시험의 누락 0을 일반 안전 근거로 쓸 수 없다. 선택지/기억 표시 어느 축이든 검토 경로가 달라진 사례는 합쳐 7/18이다. 두 축의 교차 조합은 미시험이다.

이전 점수순은 최상위 답 변화가 없어도 분포가 바뀌었다. 앞선 사후 p_max≥0.5 기준을 적용하면 원순 보존 후보 5쌍이 점수순 4쌍으로 줄었다. 기준값은 채택하지 않았다. 순환 배치 확률 평균의 제안 일치는 원순 17/36→15/36으로 낮아졌다. 모든 시험 선택지 배치에서 보존 후보인 4쌍(P01/P04/P05/S01)은 기존 규칙으로도 처리 가능해 규칙 외 추가 보존 사례는 0이다.

순서별 원자료와 분석은 memory-pilot-20261014/runs/order_study_v1에 있다. collection/order-observations.v1.jsonl에 282개 추가 모델 관찰을 기록했다. 18쌍은 실제 기록 3쌍+통제 변형 15쌍, 원문 가족 3개이며 독립 검토 완료 라벨 0이다. 모델 호출을 새 독립 사례로 세지 않는다. 선택지 고유 배치는 겹침 7–9/24개, 양립 4–6/6개여서 완전 순열 불변성을 검증한 것이 아니다. 상태 48–205토큰이며 긴 기억 묶음 위치·few-shot 예시 순서·실제 개정 적용 순서는 미시험이다. 추론 합계 511.95초·문항 중앙값 1.498초였다.

외부 1차 자료는 선택지 순서(NAACL 2024), 판정 위치 편향(IJCNLP-AACL 2025), few-shot 예시 순서(ACL 2022), Lost in the Middle(TACL 2024), Calibrate Before Use, Set Transformer, FairJudge(ICML 2026, 초록만) 등 7개를 비교했다. NAACL의 무작위 10회 집계는 Logical Deduction InstructGPT 64→72%, GPT-4 92.3→94.3%이나 우리 효과로 환산하지 않는다. 반복 안정성과 순서 안정성은 구별한다. Kev 고정 소스의 option_isolation 경로는 현재 Qwen3.5 hybrid에서 거부되므로 스위치 하나로 적용할 수 없다.

앞선 [첫 로컬 시험](../../research/sub-memory/MEMORY_PILOT_RESULTS_CODEX.md)과 [재검토 분류 연구](../../research/sub-memory/REVIEW_TRIAGE_STUDY_CODEX.md)는 보존했다. 원순 재검토 집계는 보존 후보 8·검토 10·제안상 필요 검토 누락 0·추가 검토 3이었다. 모든 보존/검토 수치는 “두 기억을 수정 없이 함께 보존할 때 양립 여부의 추가 검토”에만 한정한다. 진실성·최신성·역할별 사용·병합·삭제·대체의 검토 생략 근거로 확대하지 않는다.

현 제안은 기본 정렬을 재현 가능하게 기록하고 순서 불일치·점수 변화를 검토 신호로 수집하는 것이다. 가중합이 필수 검토 사유를 상쇄하지 않게 하고, 독립 검토와 별도 원문 가족에서 검토 누락·절감·비용을 확인한 뒤 기준값을 정한다. 순서 안정성만으로 검토를 생략하거나 자동 기억 수정을 적용하지 않았다.

- 최신 범위 정정: 외부 연구가 충분한 주제는 외부 결과의 해석과 최소 자체 검증을 중심으로 진행한다. 선행 근거가 있는 쟁점을 자체 대규모 실험·데이터 확장으로 반복하지 않는다. 원문 해석의 타당성과 우리 적용 조건을 확인하며, 기존 탐색 시험은 보조 근거로 보존한다.
- 최신 사용자 지시: 정렬·순서 변화의 영향을 시험하고 비슷한 외부 연구와 결과를 확인한다. 같은 기억의 표시 위치와 선택지 나열을 나누어 시험했고, 실제 사건·개정 시점 변경으로 확대하지 않았다.
- 최신 사용자 제안: 관계 판정 점수·가중치를 활용해 재검토 필요 여부와 수준을 분류하는 용도를 연구한다. 구체적 업무 가중치·검토 생략 기준을 승인한 것으로 취급하지 않는다. 첫 분석은 수정 없는 보존의 양립 검토로 한정했다.
- 최신 사용자 “대략 테스트를 해보고 우리데이터를 쌓아 볼까요”는 작은 실제 평가와 데이터 축적 진행 지시다. 이를 위해 전용 실험 환경·공개 가중치·로컬 실행을 준비했다. 제품 통합·자동 병합·학습·상시 수집 서비스로 확대하지 않는다.
- 최신 질문 “기억의 판단과 구별에 jevlike들이 얼마나 쓸모가 있을지 궁금합니다”에 따라 단일 구현뿐 아니라 판단 모델 계열의 역할과 기준선·평가 방법을 비교한다. 공개 점수를 우리 기억 효과로 환산하지 않는다.

- 사용자는 현재 모바일이라 첨부·파일을 열어볼 수 없다고 정정했다. 데스크톱으로 전환하면 직접 알리겠다고 했다. 그전까지 결과와 판단에 필요한 내용은 채팅 본문에서 짧게 한 부분씩 완결되게 설명한다. 파일 열람을 전제로 진행하거나 링크로 설명을 대신하지 않는다. 지속 기록은 계속 유지한다. 통제 주체·개입 시점·실패 처리·우회 경계를 우선한다.

## 미확인 사항

- 공개 jevlike 후보가 사용자가 지칭한 구현과 동일한지, 한국어 기억 관계에 유효한지, 재사용 범위와 필요한 추가 구현.
