# rsch 서브리서치 기억 지침

이 폴더는 C:\Users\ms1pk\dev\aaaNew\bootstrap\rsch\sub이며, 서브리서치 세션의 지속 기억을 보관한다.

## rsch_sub_memory 세션

- 시작·재개·문맥 압축 후 업무를 이어가기 전에 이 파일과 같은 폴더의 rsch_sub_memory.md를 읽는다. 자동 로딩을 전제하지 않고 인계된 절대 경로로 직접 읽는다.
- 자신의 기억 파일은 rsch_sub_memory.md다. 여기에 현재 업무, 사용자 정정·결정, 확인된 결과와 근거 경로, 미확인 사항, 다음 한 단계를 유지한다.
- 사용자 정정, 범위 변경, 결과 수신 또는 작업 완료가 생기면 해당 항목을 갱신한다. 오래된 현재 상태를 그대로 둔 채 기록을 끝에만 계속 덧붙이지 않는다.
- 저장한 내용을 다시 읽고 실제 반영을 확인한 뒤 저장 완료를 보고한다. 파일 저장, 다른 세션 전달, 모델 입력 포함, 실제 준수는 구분한다.
- 전체 요구사항의 원본은 ../requirements/REQUIREMENTS_CODEX.md다. 요구사항 전체를 기억 파일에 복제하지 않고 필요한 항목과 원본 링크를 적는다. 요구 변경 제안은 제안임을 표시한다.
- 기억 저장소는 이 sub 폴더다. 기존 연구 산출물 작업대는 ../rsch_sub_memory이며, 기본 cwd인 AAA에 산출물을 만들지 않는다. 모든 파일 명령에 정확한 경로를 지정한다.
- 부모 rsch의 작업 기억, 다른 세션 파일과 기존 연구 결과는 임의로 수정하거나 이동하지 않는다.
- 사용자는 모바일이다. 답변은 한 부분씩 짧게 하고, 운영 가이드보다 통제 주체·개입 시점·실패 처리·우회 경계를 우선한다.

이 지침 파일은 실행 훅이나 기술적 쓰기 차단을 설치하지 않는다. 읽기와 적용 여부는 실제 세션 응답 및 작업 기록으로 확인한다.
