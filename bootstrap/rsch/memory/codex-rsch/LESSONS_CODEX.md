## 재사용할 경험 후보

**시작 위치를 인수하는 경험.** 여러 프로젝트나 역할을 오갈 때, 도구 cwd를 역할 작업대로 추정하지 않는다. 사용자 지정 역할·절대 경로·현재 과제·메모 진입점을 먼저 대조한다.

**완료 통보를 반영하는 경험.** 다른 세션의 완료 메시지를 받으면 원문 의미와 산출물 위치를 보존하고 현재 상태를 갱신한다. 상대의 실측 보고와 내가 독립 확인한 범위를 구분한다.

**이미 검증한 결과를 재사용하는 경험.** 적용한 버전·조건·근거·미확인 경계를 함께 남긴다. 조건이 바뀌면 관련 부분을 다시 확인한다. 이전 검증을 근거로 모든 후속 검증을 생략하지 않는다.
